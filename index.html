五项信息，一个悬浮面板

不改动 Steam 的界面布局，数据都在面板里，关掉就继续逛。

悬浮面板

点击展开，拖动换位置，位置会被记住。展开与收起时，球体变形为面板，图标全程是同一个元素。无需“显示在其他应用上层”权限。

在线数据

实时在线、24 小时峰值、历史峰值、关注数。实时人数优先走 Steam 官方接口，失败时由 SteamDB 兜底。

历史最低价

跟随页面识别到的币种与定价地区，显示折扣说明、出现次数和最近日期。免费游戏自动跳过。

SteamDB 评分

读取商店页的好评和差评数，在本地按 SteamDB 公式计算，会考虑评价样本量。

最近更新

显示 SteamDB 记录的更新日期与距今天数，与在线数据共用一次查询。

请求与缓存

优先 Cronet，失败回退 HttpURLConnection。相同查询合并等待，成功结果短期复用，遇到 429 会按 Retry-After 暂停。

常见问题

更多内容见仓库 README。

安装后为什么没有悬浮球？

确认模块已启用、作用域选了 Steam、框架核心支持 API 102，然后强制停止并重新打开 Steam。仍未出现时，请附上 LSPosed 的模块加载日志提交 Issue。

为什么提示“当前不是 Steam 游戏商店页面”？

目前按 Steam 内 WebView 的商店链接（如 store.steampowered.com/app/…）识别 AppID。请进入具体游戏的详情页，首页、搜索页和社区页不适用。

史低价格为什么和别的地区不一样？

价格查询跟随商店页面的币种和定价地区，不按手机语言判断。部分美元定价地区的价格记录彼此不同。

评分为什么和 Steam 好评率不一样？

SteamDB 评分会根据评价总量做调整，不是简单的好评数除以总评价数。

可以免 Root 使用吗？

目前按支持 libxposed API 102 的框架环境开发，尚未提供经过验证的免 Root 方案。
